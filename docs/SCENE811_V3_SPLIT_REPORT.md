## 可靠性边界

场景隔离显著降低遥感裁片随机划分的空间自相关偏高风险，但任何有限检索都不能证明数学意义上的“所有潜在近邻为零”。本版本记录检索范围、模型/权重/预处理、候选和几何阈值；后续不得依据 YOLO 验证结果再次调整 split。
